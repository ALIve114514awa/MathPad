      Python 数学语法 · 本地解析、离线绘图，无需安装 Python。函数与常数直接填写名称，例如 sin(x)、pi。

      变量与运算x 为自变量，支持 + - * / ** 和括号。乘法写 *，乘方写 **（^ 为按位异或）。例如 2*x**2 - 1/(x+1)。
      根式与指数sqrt(x)、abs(x) / fabs(x)、exp(x)、pow(x, 2)。
      对数log(x) 是自然对数；log(x, 2) 表示以 2 为底，真数在前；log2(x)、log10(x) 分别以 2、10 为底。
      三角函数sin(x)、cos(x)、tan(x)；反三角函数 asin(x)、acos(x)、atan(x)。角度单位为弧度。
      常数与数值pi、e、tau（2π）；支持小数和科学计数法，例如 0.5、1e-3。
      函数与方程可直接写 x**2，也可写 y = x**2 或 lambda x: x**2。含 x、y 的二次方程使用 ==，例如 x**2/25 + y**2/9 == 1。

      每次输入一条数学表达式，按实数范围绘图。此模式支持上表中的语法子集；暂不支持 import、def、循环、数组、条件表达式、// 和 %。
