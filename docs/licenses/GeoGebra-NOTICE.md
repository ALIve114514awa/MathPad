# GeoGebra runtime used by Math Pad

Made with GeoGebra® · https://www.geogebra.org/

This directory contains unmodified files from the official GeoGebra Math Apps
Bundle 5.4.936.0. Math Pad uses deployggb.js, the shared CSS and the complete
web3d runtime. The unused web and webSimple variants are omitted. The original
README and bundled font licenses are preserved.

Official download and SHA-256 are recorded in manifest.json. The import script
checks the pinned archive hash; the build verifies every imported runtime file.
