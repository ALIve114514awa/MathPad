# Python 数学表达式输入

点击「新增公式」→「Python 表达式」，输入框下方会显示语法表和可填入的示例。点击「插入并绘图」后，曲线进入同一个函数列表，可与手写或普通键盘曲线求交、编辑和求导。

此模式解析常用 Python 数学表达式的语法子集，转为本地绘图表达式，不依赖 Python 安装。数学计算保留现有精确表达式能力，曲线按实数范围绘制，不承诺复现 Python 浮点数的舍入行为。

| 内容 | 写法与说明 |
| --- | --- |
| 变量 | 函数使用 `x`；含 `x`、`y` 的二次方程使用 `==` |
| 运算 | `+`、`-`、`*`、`/`、`**`、括号；乘法不能省略 `*` |
| 乘方 | `x**2` 或 `pow(x, 2)`；`^` 是 Python 按位异或，输入时会提示改用 `**` |
| 优先级 | `-x**2` 表示 `-(x**2)`，`(-x)**2` 表示负数的平方，`2**-x` 支持负指数，连续乘方从右结合 |
| 根式与绝对值 | `sqrt(x)`、`abs(x)`、`fabs(x)` |
| 指数 | `exp(x)`、`e**x`、`pow(x, 2)` |
| 对数 | `log(x)` 为自然对数；`log(x, 2)` 真数在前、底数在后；`log2(x)` 和 `log10(x)` 为以 2、10 为底 |
| 三角函数 | `sin(x)`、`cos(x)`、`tan(x)`，角度用弧度 |
| 反三角函数 | `asin(x)`、`acos(x)`、`atan(x)` |
| 常数 | `pi`、`e`、`tau`（2π） |
| 数值 | 小数、科学计数法及数字内分隔线，例如 `0.5`、`1e-3`、`1_000` |
| 函数 | `x**2`、`y = x**2` 或 `lambda x: x**2` |
| 方程 | `x**2/25 + y**2/9 == 1`，绘图时把 `==` 作为数学等式处理 |

函数和常数直接填写名称，例如 `sin(x)`、`log(x, 2)`、`pi`，无需库前缀。旧公式中受支持的 `math.` 写法仍可识别和编辑。普通键盘模式仍沿用原规则：`log(x)` 是常用对数、`log(2,x)` 的底数在前；切换模式时应检查当前文本是否符合所选语法。

一次只输入一个表达式或方程，最多 350 个字符。不支持导入模块、定义脚本函数、循环、文件操作、NumPy 数组、条件表达式、整除 `//`、取余 `%` 或三参数取模 `pow`。未列出的函数会提示不支持，不会当作代码执行。

错误输入会保留供修改，已有曲线继续可用。Python 曲线点「编辑」后会恢复原始文本和 Python 模式；求导时使用转换后的数学表达式，因此自然对数和指定底数的语义保持一致。隐式方程仍限于当前支持的二次曲线，含变量分母的隐式方程等限制与普通输入相同。
